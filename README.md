# Landing Page

A modern, responsive landing page with a contact form for collecting user names and phone numbers.

## Features

- ✨ Clean and professional design
- 📱 Fully responsive (mobile & desktop)
- 🎨 Gradient background with smooth animations
- ✅ Form validation
- 🎯 Success message on submission

## Files

- `landing-page.html` - Main landing page with embedded CSS and JavaScript

## How to Use

1. Clone this repository
2. Open `landing-page.html` in your web browser
3. Fill in the contact form with your name and phone number
4. Submit the form

## Customization

You can customize the landing page by editing:
- **Colors**: Modify the gradient colors in the CSS section
- **Text**: Update the header text and placeholder values
- **Font**: Change the font-family in the CSS
- **Styling**: Adjust padding, margins, and border-radius values

## Browser Support

Works on all modern browsers:
- Chrome
- Firefox
- Safari
- Edge
